# Simple Dashboard 3D

This project is a React-based dashboard featuring a 3D editor and designer management system.

## Features
- **Designer Management:** Full CRUD operations with Mock API.
- **3D Editor:** Add, select, move, and edit 3D objects using React Three Fiber.
- **Mock API:** Persistent data storage using LocalStorage.
- **Responsive UI:** Fully responsive design with Tailwind CSS and Ant Design.

## Tech Stack
- **Frontend:** React.js, Vite
- **3D Engine:** Three.js, React Three Fiber, Drei
- **UI Framework:** Ant Design, Tailwind CSS
- **Routing:** React Router Dom
